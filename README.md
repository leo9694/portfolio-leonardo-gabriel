# Portfólio — Leonardo Gabriel

Portfólio pessoal responsivo desenvolvido com React, TypeScript, Vite/vinext,
CSS moderno e Lucide React.

## Executar localmente

```bash
npm install
npm run dev
```

## Personalização rápida

- Foto, currículo e redes sociais: `app/data/portfolio.ts`
- Skills, projetos e experiências: `app/data/portfolio.ts`
- Cores e estilos: `app/globals.css`
- Conteúdo e seções: `app/components/Portfolio.tsx`

Para usar a foto, adicione o arquivo à pasta `public` e altere `profile.photo`
para o caminho público, por exemplo `/leonardo.jpg`.
